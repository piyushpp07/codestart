# Security policy

CodeStart works with local source files, provider API keys, and optional MCP
servers. Please do not open a public issue for a suspected vulnerability or for
an accidentally exposed key.

Until a public security contact is configured on GitHub, report sensitive issues
to the repository owner privately. Include reproduction steps, the affected
version or commit, impact, and a suggested mitigation when possible.

Never include real API keys, tokens, private repositories, or source code that
you are not authorized to share.
